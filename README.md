# bdd-doctor-hospital-assignment

This repository contains our solution for the Biomedical Data Design
rank-order doctor-hospital assignment mini-hackathon.

## Team Members

- Bohan Chen
- Zihan Fan
- Zheng Jian

## Problem

The goal is to assign doctors to hospitals based on doctors' ranked
preferences while respecting hospital capacity constraints.

## Planned Methods

- Main method: Minimum-cost flow
- Baseline: Greedy assignment
- Evaluation metrics: Average rank, first-choice rate, top-three rate,
  and worst assigned rank
